# Standalone nonshipping Forge 1.20.1 native support

Source-only adjunct, compiled against Forge 47.4.22 and Java 17. **Never add its JAR to the pack's `mods/` or distribution.** The `gradlew` wrapper belongs solely to this standalone Gradle project. Compilation does not grant test/world/discovery or packaging permission. For an explicitly authorized disposable runtime, run `./gradlew --no-daemon test reobfJar` and bind the exact SHA-256 of `build/reobfJar/output.jar` as `test_support`; **do not bind `build/libs/*.jar`**, whose deobfuscated `ServerGamePacketListenerImpl.player` field reference cannot resolve against the production SRG field `f_9743_`. A passing compile or a reobfuscated JAR is not native delivery or campaign qualification. Suite instrumentation classifies this nonshipping namespace only in the extracted, disposable server's crafting policy and records both original and fixture policy hashes; the candidate ZIP and source policy remain unchanged, and other unknown namespaces still fail closed.

Server-side mailbox requires the three `bc.playtest.directory`, `bc.playtest.runId`, `bc.playtest.token` JVM properties documented in `../../docs/playtest-protocol-v2.md`. The directory and `requests/` must already exist, and `capabilities.json` must not exist. On server startup the observer writes `capabilities.json`; only then process sequential `requests/%012d.json` on the server END tick. Unknown envelope/run/token/sequence fails closed, stopping mailbox processing without forging an attributed receipt. Valid unknown drivers receive `started` then `failed`. Each accepted request yields one `started`, optional samples (currently none) and one terminal observation in `observations.jsonl`, flushed before moving to next sequence. This is **not** a gameplay oracle: Kotlin evaluates raw observations independently.
