# Standalone nonshipping Forge 1.20.1 native support

Source-only adjunct, compiled against Forge 47.4.22 and Java 17. **Never add its JAR to the pack's `mods/` or distribution.** The `gradlew` wrapper belongs solely to this standalone Gradle project. Compilation does not grant test/world/discovery or packaging permission.

Server-side mailbox requires the three `bc.playtest.directory`, `bc.playtest.runId`, `bc.playtest.token` JVM properties documented in `../../docs/playtest-protocol-v2.md`. The directory and `requests/` must already exist, and `capabilities.json` must not exist. On server startup the observer writes `capabilities.json`; only then process sequential `requests/%012d.json` on the server END tick. Unknown envelope/run/token/sequence fails closed, stopping mailbox processing without forging an attributed receipt. Valid unknown drivers receive `started` then `failed`. Each accepted request yields one `started`, optional samples (currently none) and one terminal observation in `observations.jsonl`, flushed before moving to next sequence. This is **not** a gameplay oracle: Kotlin evaluates raw observations independently.

Authored fixture items are not natural resource acquisition. Cleanup restores player-owned vanilla inventory/food/effects but does not validate external mod capabilities, world drops, block changes or unrelated concurrent world mutations; use a disposable world and treat any such state as unsupported by this cleanup receipt. There is no real-client network-handshake attestation, complete tree census, external thermal readout, safe death stimulus, or full mod-specific inventory catalogue. The synthetic scale action is not a genuine human-player-login test, and merely compiling it cannot establish cohort conformance or a successful cleanup. The Thirst/WaterPurity adapter is read-only and fails if its pinned API is absent. `supported_drivers` is an API inventory, **not** proof any campaign case passed. Compilation of this module alone cannot prove JVM launch, protocol file interaction, native event delivery or actual gameplay semantics.
